# Glauco Siliprandi — Portfolio

Personal portfolio website and project showcase, live at
**[glacode.github.io/portfolio](https://glacode.github.io/portfolio/)**.

Software developer since the early 1990s, working across enterprise systems,
data warehousing, and modern AI developer tooling. Most of my professional
career has been at ASST Mantova (Mantua General Hospital), where I design and
operate the institution's analytical and reporting systems.

## Features

- **Built with**: Vite, React, TypeScript.
- **Routing**: `react-router-dom` (SPA).
- **Styling**: Plain CSS (Minimalist & Professional), with light/dark themes.
- **Deployment**: Automated via GitHub Actions to GitHub Pages.
- **Data-Driven**: Content is managed in `src/data/`.

## Getting Started

### Prerequisites

- Node.js (v20+)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Deployment

Deployment is automated via GitHub Actions on every push to the `main` branch.
The site is hosted at `https://glacode.github.io/portfolio/`.
